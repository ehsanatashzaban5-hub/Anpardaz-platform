# An Market AI

## هدف
AI آن مارکت باید روی داده واقعی An Market کار کند و هرگز برای قیمت، موجودی، فروشگاه، نظر یا مشخصات کالا داده‌سازی نکند.

## معماری
- UI فقط با `/api/v1/market/ai/assist` صحبت می‌کند.
- Market backend ابتدا محصولات/پیشنهادها/فروشگاه‌ها/نظرات تأییدشده را از DB می‌خواند.
- داده‌های فروشگاه و متن نظرات «داده غیرقابل اعتماد» محسوب می‌شوند و هرگز دستور مدل تلقی نمی‌شوند.
- سپس یک context محدود و grounded به AI Gateway ارسال می‌شود.
- AI Gateway مستقل از provider است و provider policy از DB خوانده می‌شود.
- providerهای قابل پشتیبانی فعلی: OpenAI، Gemini و OpenAI-compatible.
- تغییر provider نباید UI، API یا مدل داده Market را تغییر دهد.

## قابلیت‌ها
1. دستیار محصول: توضیح مشخصات، تفاوت‌ها و نکات خرید بر اساس داده واقعی.
2. مقایسه: مقایسه چند محصول انتخاب‌شده بر اساس مشخصات و پیشنهادهای موجود.
3. جستجوی معنایی: پیدا کردن محصولات مرتبط از catalog واقعی.
4. دسته‌بندی خودکار: ابتدا mapping/rule قطعی؛ موارد نامطمئن وارد classification queue می‌شوند تا AI یا ادمین بررسی کند.
5. تحلیل نظرات: فقط نظرات published؛ reviewهای pending/rejected هرگز خوراک پاسخ عمومی نیستند.
6. پیشنهاد خرید: فقط به شکل توضیح factual و با اعلام نبودن داده، نه ساختن قیمت/موجودی.
7. AI moderation برای نظرات قبل از انتشار.
8. تحلیل رفتار و جستجو در آینده، با رعایت حداقل‌سازی داده و کنترل دسترسی.

## امنیت AI
- prompt injection داخل عنوان/توضیحات/نظر فروشگاه قابل اعتماد نیست.
- هیچ URL، متن فروشگاه یا review اجازه اجرای دستور به مدل ندارد.
- PII غیرضروری به provider ارسال نمی‌شود.
- context و طول ورودی محدود است.
- idempotency و execution log از طریق AI Gateway ثبت می‌شود.
- API key فقط در secret/env سرور قرار می‌گیرد؛ هرگز در mobile/web bundle قرار نمی‌گیرد.

## چیزی که برای انتشار لازم است
در زمان انتشار فقط حداقل **یک API key معتبر** برای provider انتخابی لازم است:
- OpenAI: `OPENAI_API_KEY` و در صورت نیاز `OPENAI_MODEL`
- Gemini: `GEMINI_API_KEY`
- OpenAI-compatible: `AI_COMPAT_API_KEY`, `AI_COMPAT_BASE_URL`, `AI_COMPAT_MODEL`

در محیط توسعه بدون key، UI و backend باید خطای شفاف «AI در دسترس نیست» بدهند و نباید پاسخ جعلی تولید شود.

## نکته مهم
«رایگان» بودن مدل به معنی بدون هزینه عملیاتی نیست؛ اگر provider رایگان یا مدل self-hosted انتخاب شود، quota/شرایط آن باید هنگام انتشار دوباره بررسی شود. طراحی فعلی عمداً provider-agnostic است تا بعداً بدون بازطراحی An Market provider عوض شود.
